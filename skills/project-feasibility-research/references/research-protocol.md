# Multi-pass Research Protocol v0.1

The passes are sequential evidence gates, not headings added after one search.
Keep a query/evidence log so another reviewer can reproduce the route.

## 1. Breadth Scan

Map terminology, solution classes, vendors, platform limits, likely cost
drivers, delivery dependencies, and failure modes across all ten dimensions.
Do not select a winner. Record Claims to Verify and candidate Unknowns.

## 2. Primary Source Verification

For each CORE claim, look for the owning platform/vendor documentation,
regulator, law/standard text, filing, official pricing, official limit, or
first-party technical reference. If no primary source can be located, record
that as an evidence limitation; do not promote a market summary to Grade A.

## 3. Contradiction Search

For every core option, run a query designed to find incompatibility, limitation,
failure, deprecation, hidden dependency, counterexample, or evidence that its
claimed benefit does not hold. A query that merely restates the positive claim
does not count.

## 4. Alternative Search

Search for a materially different approach: build vs buy, manual-assisted vs
fully automated, browser vs native, simpler scope, different provider class, or
no-build process change. Compare it against the same decision criteria.

## 5. Critical Unknown Deep Dive

Prioritize Unknowns that can change architecture, compliance treatment, cost,
delivery, or decision verdict. Use targeted queries; if the answer is private or
project-specific, state who must confirm it instead of guessing.

## 6. Synthesis

Check every Stopping Criterion. Separate source-backed findings from inference,
state contradictions and source limitations, show cost/effort as a range or
Unknown, select a recommendation plus a distinct alternative, and issue a
verdict only if the gate passes.

## Stopping Criteria

All six kinds are required:

- `DIMENSION_COVERAGE`: every required dimension has evidence or an Unknown.
- `PRIMARY_SOURCE`: CORE claims received a documented primary-source attempt.
- `CONTRADICTION`: every core option has a counter-search and finding.
- `ALTERNATIVE`: a materially different option was searched and assessed.
- `CRITICAL_UNKNOWN`: every blocker has a resolution path and next confirmer.
- `EVIDENCE_SUFFICIENCY`: the verdict strength matches the available evidence.
